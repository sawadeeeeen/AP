# AP試験 学習トラッカー

応用情報技術者試験の学習を管理するWebアプリです。
学習記録と問題演習の結果を蓄積し、苦手分野・得意分野を可視化して、パーソナライズされた学習を支援します。

## 機能

- **ダッシュボード** — 総学習時間・解答数・正答率・未学習分野の概要
- **学習記録** — 分野ごとの学習時間とメモを記録
- **問題演習** — 問題数・正解数を記録し、リアルタイムで正答率を表示
- **統計** — 分野別の学習時間・正答率をグラフと表で確認
- **パーソナライズアドバイス** — 苦手分野の優先学習・未学習分野の案内を自動表示

## セットアップ

```bash
pip install -r requirements.txt
python app.py
```

ブラウザで `http://localhost:5000` を開いてください。

## 対応カテゴリ

AP試験の全分野（テクノロジ系・マネジメント系・ストラテジ系）に対応しています。

| 系 | 分野数 |
|---|---|
| テクノロジ系 | 12分野 |
| マネジメント系 | 3分野 |
| ストラテジ系 | 6分野 |
